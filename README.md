## 🚀 Project Overview

This dashboard provides end-to-end analytics for **Facebook marketing campaigns**, enabling marketers to:

- Monitor **Spend, Clicks, Impressions, Conversions**
- Evaluate **Campaign ROI & CTR**
- Identify **Top-performing campaigns**
- Understand audience behavior based on **Age** and **Gender**
- Make data-driven decisions to optimize ad performance

## 🔍 Insight Highlights

### **📈 Campaign Performance**
- High CTR campaigns significantly outperform others
- Certain campaigns show high spends but **low conversions**, indicating poor ROI

### **🧑‍🤝‍🧑 Audience Behavior**
- Age groups **30–34, 35–39, 40–44, 45–49** analyzed for engagement
- Gender comparison (M/F) helps optimize targeting

### **💡 Recommendations**
1. Increase budget on **high CTR & high ROI** campaigns  
2. Pause/optimize campaigns with **high spend but low performance**
